# 店分析 - 拼多多商家数据分析 SaaS 工具规划

> 状态：需求讨论阶段，**未开始开发** | 等用户说"开始做"后才启动

## 一、产品定位
- **名称**：店分析 | **类型**：第三方SaaS | **用户**：拼多多商家
- **核心价值**：后台导出数据 → 10大类86个运营指标 → 可视化仪表盘
- **付费**：按深度划分（基础免费，深度分析付费）
- **多用户兼容**：不同用户导出字段可能不同（≤参考数据），动态检测字段可用性，缺失标注"数据不足"
- **多店铺支持**：一个账号可管理多个拼多多店铺的导出数据，切换店铺查看各自分析

## 二、视觉风格
- 参考：拼多多商家后台(mms.pinduoduo.com)
- 左侧固定导航 + 顶部指标看板 + 卡片式布局
- 主色调：拼多多红(#e02e24) + 白/浅灰背景

## 三、用户体系与存储
- **必须登录才能使用**（不支持匿名）| Supabase Auth
- 前端浏览器计算 | 后端Supabase持久化
- 会员可保留长期数据、多期对比
- 一个账号可绑定多个店铺，每个店铺独立上传和分析
- **账号角色两大类**：
  - **普通用户**：正常使用数据分析，按会员等级享受权益
  - **测试用户**：拥有最高会员权限（企业版全部功能），登录后界面多一个"后台管理"按钮，跳转到管理后台
- **测试账号**：预设固定账号，用户名123456，密码123456
- **角色区分**：profiles表加role字段（normal/test），测试用户导航栏/顶部显示"后台管理"入口，普通用户不可见

## 四、数据来源与关联

### 订单CSV（核心数据源）87列×1031行
订单基础：商品、订单号、订单状态、商品数量(件)、是否审核中
时间：支付时间、承诺发货时间、承诺送达时间、发货时间、确认收货时间、订单成交时间
商品：商品id、商品规格、样式ID、一~四级类目、**商家编码-规格维度**、**商家编码-商品维度**、商家备注、买家留言
金额：商品总价(元)、邮费(元)、店铺优惠折扣(元)、平台优惠折扣(元)、多多支付立减金额(元)、上门安装费(元)、送货入户费(元)、送货入户并安装费(元)、用户实付金额(元)、商家实收金额(元)
地理：省、市、区、街道/镇、配送员手机号
物流：快递单号、快递公司
售后：售后状态
用户：消费者资料、用户购买手机号
**排查发现的额外字段**（规划中遗漏）：
- 是否直播间成交、是否直播间引导成交 → 可计算直播间订单占比
- 支付方式 → 可计算支付方式分布
- 订单来源 → 可计算订单来源分布
- 是否分期、分期期数、分期方式、手续费承担方 → 可计算分期订单占比
- 赠品相关：赠品名称/赠品id/赠品规格/赠品数量/赠品订单号 → 可计算赠品订单占比
- 货品相关：关联货品编码、货品名称、货品类型、子货品 → 可计算货品关联分析
- 仓库相关：仓库名称、仓库所在地址 → 可计算仓库发货分布
- **商家编码有两个维度**：商家编码-规格维度（SKU级）和商家编码-商品维度（商品级），裸货成本应关联商品维度

### 商品推广xlsx（核心关联）
Sheet1汇总(91×26)：日期、成交花费、交易额、投产比、总花费、净交易额、曝光量、点击量等
Sheet2商品维度(3152×46)：日期+**商品ID**+商品名称+推广场景+出价方式+总花费+交易额+投产比+曝光量+点击量+询单/收藏/关注成本等
**关联键**：商品ID ↔ 订单CSV商品id

### 明星店铺xlsx（品牌推广）
Sheet1汇总(91×12)：日期、花费、交易额、投入产出比、成交笔数、曝光量、点击量等

### 直播推广xlsx
Sheet1汇总(91×17)：日期、总花费、成交花费、交易额、投产比、曝光量、关注量、深度观看等

### 运费险xlsx（单独分类）
Sheet1(51×7)：订单编号、服务费用（元）、收费编号、收费状态、运费补偿状态、运费补偿生效时间、订单发货时间
**关联键**：订单编号 ↔ 订单CSV订单号
**可计算**：运费险总费用、运费险费用占比、运费补偿率、运费险成本核算

### 财务表格（待补充）
- 内容：店铺违规扣点罚款等费用
- 关联方式：关联商品信息，同步成本进去，**标签出成本类型**（违规/扣点/罚款等）
- 上传后分析字段结构

### 商品成本数据（关键设计）
- **关联键**：商家编码-商品维度 ↔ 商品成本表（注意：CSV有两个商家编码字段，规格维度=SKU级，商品维度=商品级，裸货成本关联商品维度）
- 每个订单的商家编码-商品维度定位卖出商品的裸货成本
- **如果商家编码缺失或无对应成本**：需要用户手动填充裸货成本
- 成本类型标签：裸货成本、运费险成本、违规罚款、扣点费用等

### 完整关联链路
```
订单CSV ──[商品id]──→ 商品推广 ──[日期+商品ID]──→ 单品推广花费
订单CSV ──[订单号]──→ 运费险 ──→ 运费险成本
订单CSV ──[商家编码]──→ 商品成本表 ──→ 裸货成本（缺失需用户填充）
明星店铺+直播推广 ──[日期]──→ 店铺级推广总花费
财务表格 ──[商品信息]──→ 违规/扣点/罚款成本（标签分类）

最终利润 = 商家实收 - 推广花费 - 运费险成本 - 裸货成本 - 违规罚款 - 扣点费用
```

## 五、86个指标 + 运费险类（新增第11大类）

### 免费指标（约52个）- 基础统计值
**销售业绩(8)**：GMV、有效销售额、订单总量、支付订单数、支付成功率、日均订单量/销售额、峰值/低谷日
**商品运营(9)**：单品销量/销售额排名、商品贡献度、SKU销量占比、单品客单价、品类销售额/销量占比、商品退货率、价格带分布
**用户行为(7)**：总支付买家数、客单价、人均购买频次、连带率、高价值用户占比/贡献度、支付方式分布
**时间趋势(4)**：24h订单分布、7天分布、下单-支付时长、支付-发货时长
**地理区域(5)**：省份/城市销售排名、区域销售占比、偏远地区占比、区域客单价差异
**物流履约(4)**：平均发货时长、48h发货率、平均物流时效、快递公司时效排名
**优惠成本(3)**：总优惠金额、优惠占比、商家实际收入
**售后质量(3)**：售后率、退款率、退款金额占比

### 付费指标（约34个）- 深度分析
**销售业绩(3)**：环比/同比增长率、销售完成率
**商品运营(9)**：动销率、SKU动销率、新品占比、爆款生命周期、复购率、差评率、组合购买率、库存周转、断货率
**用户行为(7)**：新/老买家数及占比、复购率(30/90天)、LTV、流失率
**时间趋势(6)**：月/季/年度趋势、发货-揽收时长、揽收-签收时长、订单生命周期
**地理区域(3)**：城乡占比、区域退货率差异、区域物流时效差异
**物流履约(5)**：24h揽收率、快递退货率排名、物流异常率、虚假发货率、投诉率
**优惠成本(4)**：单品/综合毛利率、ROI、盈亏平衡点
**售后质量(4)**：售后原因分布、处理时长、纠纷率、DSR分析
**营销效果(5)**：活动期间销售额/订单量/新用户增长率、客单价/连带率变化
**风险预警(5)**：订单/退款异常检测、物流异常预警、DSR预警、库存预警

### 运费险类（新增第11大类，4个指标）
| # | 指标 | 层级 | 说明 |
|---|------|------|------|
| 1 | 运费险总费用 | 免费 | 所有订单运费险服务费用之和 |
| 2 | 运费险费用占比 | 免费 | 运费险总费用÷GMV |
| 3 | 运费补偿率 | 付费 | 有运费补偿的订单数÷总订单数 |
| 4 | 运费险成本核算 | 付费 | 运费险对商家实际收入的影响分析 |

### 成本管理页面（独立页面，核心功能）
1. **缺编码SKU列表**：上传订单后，自动列出所有缺少商家编码或编码无对应成本的SKU，用户逐个填充裸货成本
2. **新品定价预设**：商家上架新品前，搭建定价公式（成本+运费+推广+利润率=售价），输入商家编码即可自动关联
3. **编码填写融入**：商家编码的填写和成本录入统一在此界面完成，与新品预设功能合并

### AI功能设计
- **后台配置AI模型**：管理员在AI配置页面设置模型参数和API
- **前台AI能力**：配置完成后，前台各分析页面出现"AI分析"按钮

## 八、技术架构
**前端**：React+Webpack+Tailwind | HashRouter | Recharts | Framer Motion | Lucide | papaparse | xlsx(SheetJS)
**后端**：Supabase Auth+PostgreSQL+Storage+Edge Functions
**DB**：profiles | stores(店铺表) | product_costs(商品成本表,商家编码关联) | file_uploads(含available_fields_json) | analysis_results | subscriptions | cost_labels(成本类型标签:裸货/运费险/违规/扣点/罚款)
**字段检测**：每个指标定义requiredFields，解析后动态检测，缺失返回INSUFFICIENT_DATA
**多店铺**：stores表关联user_id，每个店铺独立数据和分析，顶部可切换当前店铺
**成本填充**：商家编码缺失时弹出填充界面，用户手动输入裸货成本；成本类型标签化
