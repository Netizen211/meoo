# 商品关联分析页面重构计划

## 目标
将 ProductLinksPage（链接分析）重构为基于商品ID的自动关联分析页面，从当前店铺的订单和推广数据中提取商品维度，按商品ID聚合展示每个商品的全链路数据表现。

## 核心思路
- **自动提取**：从订单数据的 `商品id` 字段和推广数据的 `商品ID` 字段自动提取所有商品ID，无需手动录入
- **ID关联**：用商品ID作为唯一键，将订单数据（销量、实收、退款等）和推广数据（花费、点击、成交等）关联到同一个商品
- **全链路画像**：每个商品展示订单维度 + 推广维度的完整指标

## 数据字段映射
| 数据源 | 字段 | 用途 |
|--------|------|------|
| 订单数据 | `商品id` | 商品唯一标识（关联键） |
| 订单数据 | `商品` | 商品名称 |
| 订单数据 | `商品数量(件)` | 销量 |
| 订单数据 | `商家实收金额(元)` | 实收 |
| 订单数据 | `商品总价(元)` / `用户实付金额(元)` | GMV |
| 订单数据 | `退款金额(元)` | 退款 |
| 订单数据 | `店铺优惠折扣(元)` + `平台优惠折扣(元)` | 折扣成本 |
| 订单数据 | `售后状态` | 售后/退款判定 |
| 推广数据(商品) | `商品ID` | 商品唯一标识（关联键） |
| 推广数据(商品) | `商品名称` | 商品名称 |
| 推广数据(商品) | `总花费(元)` / `花费(元)` | 推广花费 |
| 推广数据(商品) | `点击量` | 推广点击 |
| 推广数据(商品) | `曝光量` / `展现量` | 推广曝光 |
| 推广数据(商品) | `成交笔数` / `成交订单数` | 推广成交 |
| 推广数据(商品) | `交易额(元)` | 推广交易额 |

## 修改文件清单

### 1. `src/pages/ProductLinksPage.tsx` — 完全重写
**改动量 > 90%，使用 Write 重写**

新页面结构：
- 页面标题改为"商品关联分析"
- 副标题说明：基于商品ID自动关联订单与推广数据
- **KPI汇总区**（8个指标卡片）：总GMV、总实收、总推广花费、总折扣、总成本、净利润、平均ROI、退款率
- **筛选区**：ROI筛选（盈利/亏损/持平）、最低订单数、最低GMV、搜索框（按商品名称/ID搜索）
- **视图切换**：表格视图 / 卡片视图 / 图表视图
- **商品列表**：自动从数据中提取，按商品ID聚合

核心逻辑：
```
1. 从 currentDisplayData.orders 提取所有商品id → 构建商品集合
2. 从 currentDisplayData.promotionProducts 提取所有商品ID → 合入商品集合
3. 对每个商品ID：
   - 聚合订单数据：销量、实收、GMV、退款、折扣、售后率
   - 聚合推广数据：花费、点击、曝光、成交、CTR、CVR
   - 计算衍生指标：ROI、净利润、利润率、客单价、折扣占比、推广占比
4. 排序、筛选、展示
```
