# 代码审查助手

## 任务目标
- 本 Skill 用于：自动化代码审查流程
- 能力：
  - 分析代码结构和复杂度
  - 检测潜在问题和代码异味
  - 生成详细的审查报告
  - 提供具体的改进建议
- 触发：当用户提到"代码审查"、"review code"、"检查代码质量"、"代码优化建议"时使用

## 前置准备
- 依赖说明：使用 @babel/parser 和 @babel/traverse 进行代码解析
- 无需额外系统命令

## 操作步骤

### 1. 代码分析
- 读取用户提供的代码文件
- 使用 Babel 解析器分析代码结构
- 识别函数、类、变量等关键元素

### 2. 质量检查
- 检查代码复杂度（圈复杂度）
- 检测未使用的变量和导入
- 识别潜在的错误模式
- 评估代码可读性

### 3. 生成报告
- 汇总发现的问题
- 按严重程度分类（错误、警告、建议）
- 提供具体的改进代码示例

### 4. 输出结果
- 生成 Markdown 格式的审查报告
- 包含问题统计和详细说明
- 提供修复优先级建议

## 注意事项
- **附件读取规则**：当任务涉及代码审查时，**必须优先读取** references/ 中的相关文档，不要凭推测执行
- **脚本调用规则**：遇到复杂代码分析时，**立即调用** scripts/ 中的对应脚本，而不是尝试自行解析
- **资源使用规则**：需要生成报告时，**直接使用** assets/templates/ 中的模板，不要重新创建
- 充分利用智能体的代码理解能力，避免为简单审查编写脚本
- 对于简单的代码问题，可以直接由智能体分析并给出建议
