# 代码复杂度评估指南

## 概览
定义代码复杂度的评估标准和阈值，用于量化代码质量。

## 圈复杂度 (Cyclomatic Complexity)

### 计算方法
- 基础值: 1
- 每个条件分支 (if/else/switch/case): +1
- 每个循环 (for/while/do): +1
- 每个逻辑运算符 (&&/||): +1
- 每个 catch: +1

### 阈值标准

| 复杂度 | 评级 | 建议 |
|--------|------|------|
| 1-5 | ✅ 简单 | 无需优化 |
| 6-10 | ⚠️ 中等 | 关注即可 |
| 11-20 | 🔶 复杂 | 建议重构 |
| 20+ | 🔴 危险 | 必须重构 |

## 认知复杂度

### 评估维度
1. **嵌套深度**: 建议不超过 3 层
2. **条件数量**: 单个函数建议不超过 5 个
3. **返回点**: 建议不超过 3 个

### 评分示例
```javascript
// 复杂度: 2
function simple(a) {
  if (a > 0) return a;
  return 0;
}

// 复杂度: 4
function complex(a, b) {
  if (a > 0) {
    if (b > 0) {
      return a + b;
    }
  }
  return 0;
}
```
