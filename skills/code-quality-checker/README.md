# Code Quality Checker Skill

代码质量检测技能，在代码更新完成后自动进行多维度质量检测。

## 快速开始

### 基本使用

直接向 Meoo Agent 描述检测需求：

```
对本次代码变更进行质量检测
```

```
扫描这个模块的安全漏洞
```

```
检查测试覆盖率是否达标
```

## 检测能力

| 检测类型 | 描述 | 触发词 |
|---------|------|--------|
| 代码规范 | 命名、格式、风格检查 | 规范检测、代码风格 |
| 安全漏洞 | SQL注入、XSS、敏感信息泄露 | 安全扫描、漏洞检测 |
| 性能问题 | N+1查询、内存泄漏、性能瓶颈 | 性能分析、性能检测 |
| 测试覆盖 | 覆盖率、边界条件、异常测试 | 测试覆盖、覆盖率检查 |
| 依赖安全 | 已知漏洞、过时依赖 | 依赖审计、依赖检查 |
| 代码复杂度 | 圈复杂度、函数长度、嵌套深度 | 复杂度分析 |

## 检测报告

检测完成后会生成结构化报告，包含：

- **概览统计**：问题总数、严重程度分布
- **详细问题**：文件位置、问题描述、修复建议
- **质量评分**：综合质量分数和改进建议

## 质量门禁

可配置质量门禁规则，在代码合并前自动阻断不符合标准的变更：

```yaml
qualityGate:
  security:
    critical: block  # 严重安全漏洞阻断
  coverage:
    minimum: 80      # 测试覆盖率要求
```
